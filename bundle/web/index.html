The loop

The setup that makes rising scores mean better code. Full details →

  1. GradeThree independent graders audit the same commit, each in a fresh sandbox.
  2. Checkgradekit validate and verify-evidence reject bad reports.
  3. Consensusgradekit stability takes the median and flags unstable benchmarks.
  4. Redactgradekit redact strips hidden-check results before sharing.
  5. DecideHumans answer decision questions and record accepted findings.
  6. ImproveImprovers clear caps first, then maturity blockers, and stop at each target.
  7. GuardPR quick mode plus gradekit diff --fail-on-regression on every change.
