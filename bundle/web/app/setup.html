4Answer eight questions

Each answer nudges specific weights up or down, and some make a benchmark a gate (non-negotiable). The chips show what each answer does.

5Mark critical code

Hot zones (money, auth, data writes) count more: problems there are one severity higher, and fixes rank first. Cold zones (scripts, examples) count less. Everything else is normal. The first matching zone wins, so put specific ones first.

Patterns: ** matches any number of folders, * matches within one folder, and a trailing / means everything under it.
